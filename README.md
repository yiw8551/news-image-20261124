A deterministic, standard-library-only Python program that sums up the world news of Tuesday 24 November 2026 in a single 1024x1024 PNG. The front page carries 34 stories from 8 regions: three featured tiles (Nvidia restoring Jensen Huang as CEO, Medvedev floating a preventive nuclear strike, and Sanofi's $41 billion Insmed deal) plus 31 compact numbered stories spanning the Russia-Ukraine war, Europe, the Middle East, Asia, Africa, Latin America, North America and global news — from Ukraine sinking a Russian warship off Libya and the leaked Rosstat toll of some 490,000 registered Russian war dead, to NATO's AWACS deployment to Poland, the UK recognising the Rohingya genocide, China's probe of a Politburo member, drone strikes on Khartoum, and Virginia and Oregon suing Musk's SpaceX firms over Grok. The program ships its own bitmap font and PNG encoder, uses no network or external files, and produces byte-identical output on every run.

## Run it

```sh
python3 main.py
```

Writes `/output/entry.png` if that directory exists, otherwise `./output/entry.png`.
